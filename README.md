# Demon Quest — legal & support pages

Static GitHub Pages site for Demon Quest : Dungeon RPG (Android, com.victorygames.demonz), published by Zintex OÜ.

- `index.html` — support page + FAQ + data deletion (use as **Support / Website URL**; `#delete-data` as the **data deletion URL**)
- `privacy.html` — privacy policy (use as **Privacy Policy URL**)
- `terms.html` — terms of use

Enable Pages: repo **Settings → Pages → Deploy from branch → main / (root)**.
